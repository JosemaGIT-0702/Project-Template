# Literature

One file per paper, named by INSPIRE texkey with `:` replaced by `_` (`Maldacena_2018lmt.md`;
Windows forbids `:` in file names), with:
arXiv/DOI, one-paragraph summary, conventions used (and how they map to ours),
results we use or compare against (with equation numbers).

PDFs go in `literature/pdf/` (git-ignored).
